# GCU-BENIN - Site Web Officiel

**GÉNIE CIVIL UNIS — BÉNIN**

> *« Unis par le génie civil, bâtissons l'avenir du Bénin. »*

## 📁 Structure du projet

```
gcu-benin/
├── html/                  # Toutes les pages HTML
├── css/
│   └── style.css         # Styles principaux (responsive, animations)
├── js/
│   ├── main.js           # Scripts principaux
│   └── config.js         # Configuration globale du site
├── assets/
│   ├── images/           # Logo, photos, bannières
│   ├── icons/            # Icônes SVG
│   └── fonts/            # Polices personnalisées
├── admin/                 # Interface d'administration sécurisée
└── documents/             # Ressources techniques (PDF, etc.)
```

## 🚀 Déploiement

Le site peut être déployé sur :
- GitHub Pages (gratuit)
- Cloudflare Pages (gratuit)
- Vercel (gratuit)
- Tout hébergeur static

## 🔧 Installation locale

1. Clonez le dépôt :
```bash
git clone https://github.com/gbodogbejores5-a11y/gcu-benin.git
cd gcu-benin
```

2. Ouvrez `index.html` dans votre navigateur

## 📝 Personnalisation

1. Remplacez les images dans `assets/images/`
2. Modifiez les couleurs dans `css/style.css`
3. Mettez à jour les informations de contact dans `js/config.js`
4. Personnalisez le contenu des pages HTML

## 🛡️ Sécurité

- Aucun CDN externe
- Toutes les dépendances sont locales
- Formulaires protégés contre le spam
- Validation côté client et serveur
